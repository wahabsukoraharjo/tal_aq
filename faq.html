Cara Menggunakan
Klik node pada flowchart untuk membuka Process FAQ & Activity Plan dalam pop-up.
Tidak perlu scroll ke bagian detail
Setiap proses akan membuka pop-up berukuran besar. Isi detail dapat di-scroll di dalam pop-up, sementara posisi flowchart di halaman utama tetap tidak berubah. Pop-up dapat ditutup melalui tombol ×, tombol Tutup, klik area gelap di luar pop-up, atau tombol Esc.
Catatan desain: tampilan ini dibuat sebagai Management / FAQ View. Flowchart menjadi ringkasan eksekutif, sementara detail activity plan tetap tersedia saat setiap proses diklik. Data activity saat ini adalah draft berdasarkan flow yang diberikan; nantinya dapat diganti langsung menggunakan file Excel final.
